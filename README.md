# ForgeDB

ForgeDB is a lightweight relational database engine built from scratch in C++20.

The project focuses on understanding and implementing core database internals rather than relying on an existing database engine.

## Planned Components

- Page-oriented storage engine
- Disk manager
- Record management
- Schema and catalog management
- SQL tokenizer and parser
- Query execution engine
- B+ tree indexing
- Buffer pool and LRU replacement
- Transactions and concurrency control
- Write-ahead logging
- Crash recovery
- Unit and integration testing
- Performance benchmarking
